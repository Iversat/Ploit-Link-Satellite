# Ploit Satellite — Connection Assistant

Нативное приложение iPhone на SwiftUI, в визуальном стиле предоставленного пользователем скриншота Connection Assistant. Отдельный независимый проект, не системное приложение Apple.

## Возможности

- Ночная Земля NASA Black Marble 2016, атмосферное свечение, полупрозрачные карточки.
- МКС, SONATE-2, SO-50, ARICA-2 и CroCube; отдельные радиорежимы и источники частот.
- SGP4/SDP4 через локальный satellite.js 6.0.1 (MIT) в JavaScriptCore. Код расчёта не загружается из сети.
- Реальные азимут, угол места, наклонная дальность, радиальная скорость, информационные поправки Доплера.
- Прогноз окон на 48 часов с маской горизонта 0–30°, уточнение границ до 0,25 с. Очень короткие окна между 15-секундными шагами могут быть пропущены.
- Наведение по Core Motion и Core Location; выбор верхнего торца либо задней нормали телефона, индикатор угловой ошибки, вибрация при совпадении.
- После загрузки TLE расчёт работает без интернета. Возраст орбиты виден; после 3 суток предупреждение, после 14 суток наведение блокируется.
- Ручные координаты, явная учебная цель 135° / 45°, без мнимого подключения к спутнику.
- Геопозиция не отправляется на сервер. Запросы CelesTrak содержат только NORAD ID. Аналитика и рекламные SDK отсутствуют.

## Готовый IPA без локального Mac

Откройте **Actions → Build unsigned IPA → последний успешный запуск → Ploit-Satellite-unsigned-IPA**. В ZIP-артефакте находится `Ploit-Satellite-unsigned.ipa` и SHA256. Это настоящая сборка arm64 для iPhone, упакованная в Payload, без подписи Apple. Подпишите своим способом перед установкой. Симуляторный .app не подменяет IPA.

GitHub использует свой Mac-сервер (`macos-15`). Workflow генерирует Xcode-проект через XcodeGen, запускает тесты SGP4, собирает Release для iphoneos, проверяет IPA/Mach-O, запускает нативные тесты и снимает экраны в симуляторе. Никакие сертификаты не нужны для этой сборки.

Для ручного повторного запуска нажмите **Run workflow**. При отправке в main сборка запускается автоматически. Сборка может расходовать минуты GitHub Actions для закрытого репозитория согласно лимиту аккаунта; увеличенные платные серверы не используются.

## Установка и наведение

1. Подпишите IPA своим сертификатом/инструментом и установите на iPhone с iOS 17+.
2. Разрешите геопозицию и движение. Для точного направления требуется компас, а не только гироскоп.
3. Выберите спутник, затем радиорежим. Уточните статус оператора по ссылке в карточке.
4. В настройках выберите ось наведения под диаграмму реальной антенны. У обычного штыря максимум излучения поперёк штыря; ось конструкции нельзя автоматически считать максимумом.
5. Откройте «Наведение на спутник», совместите точку с центром. Зелёное совпадение требует истинного севера, допустимой точности компаса и видимого спутника.

## Физические ограничения

Приложение не даёт стороннему коду доступ к спутниковому модему iPhone. Для передачи VHF/UHF и декодирования нужен отдельный радиомодуль/антенна. В текущей версии радиоуправление, BLE-протокол ESP32, передача пакетов и подтверждения доставки не реализованы. Совпадение наведения — геометрия, а не измеренный сигнал. Передавать допустимо только по разрешённому оператором режиму и с необходимыми правами радиолюбительской станции.

Частоты проверены 19.10.2026. ARISS указывает APRS МКС 437,825 МГц в испытаниях (статус 07.10.2026); автоматически использовать старые 145,825 нельзя. Для SONATE-2 APRS 145,825 МГц зависит от активации. Известное окно ARICA-2 29.09–13.10.2026 закончено; доступность нового окна не подтверждена. SO-50 — голосовой FM, CroCube — приём телеметрии. «150» без уточнения означает диапазон, не идентификатор спутника.

Компас рядом с MagSafe, аккумулятором, токами передатчика и металлом может ошибаться. Качество связи и физическая точность наведения требуют проверки на iPhone с готовой антенной. По одному скриншоту невозможно подтвердить побайтовое совпадение всех экранов закрытого системного интерфейса Apple; предоставленный главный экран воспроизведён своим кодом, экран наведения продолжает его визуальный стиль.

## Проверки

`node tools/test-orbit.cjs` проверяет контрольные суммы TLE, конечность координат, производную дальности, границы прогнозируемых окон и независимый опубликованный тестовый вектор Vallado (SGP4, спутник 00005, t=0).

`Tests/AimTests.swift`: оси север/восток/верх, переход 359→1°, зенит, знаки Доплера, загрузка локальных TLE и мост JavaScriptCore.

`tools/verify-ipa.py`: Payload, Info.plist, исполняемый Mach-O и обязательные ресурсы.

Снимки `Native-QA/screenshots` созданы самим iOS-приложением в симуляторе. Снимок наведения использует обозначенную учебную цель и синтетическую ориентацию, он не доказывает работу датчиков на физическом телефоне. Debug-флаги снимков отключены в Release IPA.
